Built to run on your machine, not the cloud.

Four decisions shape everything else: your data is local, it works offline, the code is open, and the workflow bends to you.

Local SQLite database

One SQLite file holds everything. Back it up, move it between machines, or open it in any SQLite tool. No proprietary format, no export dance, no lock-in.

%APPDATA%/praxisos/praxisos.sqlite3

Offline-first

Every feature works with the network unplugged. The only time PraxisOS reaches the internet is to check for its own updates.

Open source

Read every line, build it yourself, or send a patch. The whole app is public on GitHub.

Browse the repository

Custom workflows

Shape tasks, habits, and roadmaps around how you actually work, then keep them all in step from one dashboard. The structure is yours to bend, not a template to obey.

Nothing leaves your machine.

No account, no sync server, no telemetry. All of it lives in one file on your disk, and it stays there.

The only network calls PraxisOS makes are to fetch its own updates. Everything else is yours, offline, on disk.
